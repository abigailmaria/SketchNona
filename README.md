# SketchNona

A simple SketchNona Tool for Auto scaling.

With SketchNona, you get a lightweight tool that stays out of your way.

**What you get**

- A simple SketchNona Tool for Auto scaling

## Key Features

- A simple SketchNona Tool for Auto scaling

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchNona.git`
2. `cd SketchNona`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
